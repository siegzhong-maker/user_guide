# Falcon vs 变色龙：录制前引导对照表（评审用）

本文档与原型中的存储键、分支逻辑一致，便于评审与验收对齐。

## 总览

| 维度 | Falcon | 变色龙（Chameleon） |
|------|--------|----------------------|
| 产品定位 | 霍尔校准 + 架设说明 + 界面操作蒙层 | 线性多页「录制前说明」 |
| 必经（默认不因「不再提示」关闭） | 霍尔校准流程（首次/未校准） | 无独立霍尔校准步骤时，整套更接近纯教育内容 |
| 「不再提示」粒度 | **一条键**：UI 引导**最后一步**勾选，控制架设引导 + UI 蒙层均不再自动播放（霍尔校准仍独立） | **一条键**：整段四步引导不再自动播放 |
| 常驻入口 | Tutorial Center（`?`） | 同上 |

## Falcon：步骤与存储键

| 步骤 | 自动弹出条件 | localStorage 键（原型） | 「不再自动展示」是否适用 |
|------|----------------|---------------------------|----------------------------|
| 霍尔校准 | 首次进入且未完成校准 | `tw_proto_hall_v1`（`LS_CAL`，完成后写 `1`） | **不适用**（与「操作提示」文案区分） |
| 架设引导（Hall guide） | 校准完成后，且未勾选「不再展示整套引导」 | 包含在 `LS_FALCON_SKIP_AUTO_GUIDES` 中 | **适用**（与 UI 蒙层同一开关，仅在末步勾选） |
| UI 蒙层（live / record） | 架设流程结束后，且未完成或已勾选末步 | 同上 `tw_proto_falcon_skip_auto_guides_v1` | **适用** |

兼容：历史 `tw_proto_never_v1`、旧版 `tw_proto_falcon_skip_setup_tips_v1` / `tw_proto_falcon_skip_ui_hints_v1` 会迁移为统一的 `tw_proto_falcon_skip_auto_guides_v1`。

## 变色龙：步骤与存储键

| 步骤 | 内容概要 | 存储 |
|------|-----------|------|
| 1～4 页 | **中线对齐** → **脚架高度（≥2.2 m）** → **左侧模式/UI** → **红点录制**（末页可勾选不再展示；已去掉首屏泛推荐文案） | 整套是否不再自动播放：`tw_proto_chameleon_carousel_skip_v1`（末页勾选后为 `1`） |
| Skip | 任意页可跳过整段 | 关闭层叠，不写入跳过标志（与产品策略一致时可改为写入） |

设备分支：`tw_proto_device_family_v1` 值为 `falcon` 或 `chameleon`。

## 验收对照（摘要）

- **Falcon**：在 UI 引导最后一步勾选「不再展示」后，写入统一键；下次校准完成后不再自动播放架设引导与 UI 蒙层；霍尔校准仍按原逻辑执行。
- **变色龙**：勾选末页「不再展示」后，进入取景不再自动播四步流程；Tutorial Center 仍可手动打开。
- **两端**：`?` / Tutorial Center 与自动引导开关相互独立。
